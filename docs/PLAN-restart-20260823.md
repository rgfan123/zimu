## 前端差距分析的三个票面修正（2026-08-23 扫描确认，实现时以此为准）

1. **频控「今日剩 N 次」不是零后端改动**：`ConnectorConfig` DTO 不含 `last_pull_at`，前端推导不出剩余额度。
   #107 首发按 ADR 0001 显示「配额状态未接入」诚实态；后端暴露字段并入加固票 02 的 B 部分。
2. **七指标中「仅报告未入库」只存在于 refresh 响应瞬时值**，刷新后无处可查；八段链路无按段聚合端点，
   且 ProcessingStage 八值与原型八段是两条不同轴——#108 实现时先定义映射，不可得的段位显示「暂无汇总」。
3. **全局搜索 ⌘K 无后端端点**（最接近的是 `orders?query=`）：外壳阶段做占位入口 + 「未接入」态，
   不伪造跨对象搜索。
4. 利好：`PageState.tsx`/`useAsync.ts`/`errorMessage` 三态基础设施已成体系、全站无假数据残留、
   `saasTheme.ts` 色板与原型同源——重构是壳层重建 + 视觉规约收紧 + 页面重排，不是错误处理重写。
   新工作台强制沿用 PageState/useAsync，禁止另起炉灶；禁止复制 DashboardPage 跨页拉全量反模式
   （fetchOpenReviewCases size=200 循环），计数用 size=1 取 total_elements。
