# ADR 0017：商品离散数量使用整数，包装资料缺失仅告警

商品件数、来源份数、包装乘数、礼包及组件数量、履约和回填数量统一属于 `CountQuantity`，在系统内部和 JSON 契约中使用整数；来源 Excel 中数学上恰为整数的旧表示（如 `3.000`）只在适配器边界精确归一为 `3`，真实小数不得舍入。重量、净含量、体积和金额继续使用十进制量。

SKU 的净含量与包装四字段属于可完善的包装资料，不是履约身份。四字段全空只产生数据质量警告，不阻断成单、导出或发货；一旦填写则必须成组完整且与可确定解析的展示规格一致。SKU、商品或履约方停用，来源/履约方映射缺失，计数单位或京东件数换算非法，以及明确未裁决的冲突仍是硬阻断。

选择这一边界，是为了避免不影响“发什么、由谁发、发几件”的展示资料缺失压停真实履约，同时保留对相互矛盾主数据的失败关闭。
