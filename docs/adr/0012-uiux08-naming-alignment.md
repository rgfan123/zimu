# ADR 0012: 命名与领域词汇对齐（UIUX-08）

- 日期：2026-08-25
- 状态：已接受
- 关联：rgfan123/zimu#142（UIUX-08）

## 背景

菜单名与页面标题存在同页不同名：菜单「文件作业」对应页面标题「销售出库」；侧边栏
「调度台」对应页头「工作台」。命名漂移让操作员难以确认自己所在页面，也让导航语境
（navigationContext 面包屑/归属）与页头不一致。

## 决策

1. **同页同名，以菜单名为准**（侧边栏是唯一事实源 `appNavigation`）：
   - `/fulfillment/sales-outbound` 页统一为「文件作业」——页面标题、错误文案、测试断言
     全部改为菜单名；路由路径 `/fulfillment/sales-outbound` 保持不变（URL 不删改）。
   - `/dashboard` 页统一为「调度台」——PageShell 标题从「工作台」改为「调度台」；
     页面内部数据语义（工作台数据/明细）保持不变。
2. **来源渠道清单以系统枚举为准**：`SourceChannel` 枚举与 `CHANNEL_LABELS` 已含
   DAZHE（大者）/ WANQI（万齐）/ WANGQI（历史技术兼容值），CONTEXT.md 术语表同步
   （已含全部渠道定义）；后续渠道变更须同时更新枚举、标签表与 CONTEXT.md（对账测试
   `enumLabelReconciliation.test.ts` 保证缺译即失败）。

## 备选

- 以页面业务名「销售出库」为唯一名：被拒——「文件作业」更贴合页面职责（履约导出 +
  回传 + 来源回填的文件闭环），且导航准入文档与 #144 信息架构草稿均使用「文件作业」。

## 影响

- 页面标题变化会改变 PageShell 渲染文本；测试断言同步更新。
- 不改任何 URL、路由或 API 契约。
