# Price suggestion rule: trim one extreme quote each side, recommend from the middle band

Grilling 2026-08-23（用户确认规则理解 + 拍板盯盘品清单形态）。

## 建议规则（每个盯盘品独立计算）

1. 汇总两平台（牧集/肉交所）白名单厂当日全部报盘，统一换算元/千克
   （沿用 Demo 的防 1000 倍换算与"识别不到单位标待核拒绝硬算"）。
2. **报盘 ≥5 个：剔除最高 1 个、最低 1 个**（极值可能虚标或品质异常）；
   **<5 个：不剔除，只标注"样本不足，未剔除极值"**。
3. 建议从中间报盘出：推荐中间带最低价厂，附次选与对昨日中间价的涨跌。
4. **"中间"指报盘不指品类**：所有盯盘品都给建议；被剔除的报盘照样落盘、
   照样展示并标"已剔除：最高价/最低价"（同事 ADR-002：全量展示，AI 不藏牌）。

## 盯盘品清单

- 做成**系统内可编辑界面**（用户拍板"按原型形式来"，不走配置文件）。
- 形态：采购工作台建议区头部"管理盯盘品"入口 → 清单编辑页/抽屉；
  按 navigation-admission 规则注册为上下文二级入口（低频配置，不占一级菜单位）。
- 修改即存库，下一次采集周期生效。

## Considered options

- 按比例剔除（上下各 10%）：rejected —— 报盘量级只有个位数，比例剔除在小样本上
  退化为 0 或过度剔除，固定各 1 个 + 样本不足标注更可预期。
- 只对部分品类给建议：rejected —— 用户确认"中间"指报盘维度。
- 盯盘品写死配置文件（Demo 做法）：rejected —— 用户拍板要界面化。
