# 08: 统一来源礼包解析接缝

**What to build:** 文件导入、平台 API 拉单和人工礼包解析使用同一个来源礼包接缝与稳定来源键，保留现有 ID/名称映射兼容，同时让新的来源 SKU 引用成为可审计事实。

**Blocked by:** 01: 建立隔离收敛来源账本与只读门禁。

**Status:** ready-for-agent

- [ ] 三种入口对同一来源引用产生同一礼包解析结果。
- [ ] 现有 ID 键和名称键映射继续工作，不以模糊猜测自动关闭复核。
- [ ] 新数据库变化使用高于当前基线的追加式迁移，历史迁移保持不变。
- [ ] schema 快照、迁移兼容与业务 API 契约同步。
- [ ] 纯测试和真实 PostgreSQL/Testcontainers 验收状态分别报告，并形成独立提交。
