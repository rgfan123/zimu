**What to build:** 工具注册表向 Agent 调用者和公共 MCP 调用者提供两套明确、不可混淆的工具面；新增业务读工具只能通过正确模块进入对应工具面，公共工具面始终保持只读。

**Blocked by:** 04: 收编 stdio 写工具门禁。

**Status:** ready-for-agent

- [ ] Agent 与公共协议工具索引、查找和模块配置互相独立。
- [ ] 未知模块启动即失败，显式空配置产生空工具面。
- [ ] 公共工具面即使误配写模块也拒绝列出和调用写工具。
- [ ] 既有 Agent 绑定、门禁、审计与 MCP 调用行为保持兼容。
- [ ] 原有与新增聚焦测试通过，并形成独立提交。
