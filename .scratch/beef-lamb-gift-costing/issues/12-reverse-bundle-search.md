# 12 — 反向组合的约束集合与目标函数

**Type:** grilling
**Status:** open
**Blocked by:** 07、08、13

## Question

正向是「给了组合算成本」，反向是「给了目标搜组合」。用户样例输入：

```
期望对外售价 400 元 / 客户采购价 300 元
牛羊礼包 3800g
牛腩块500g×1、牛腱子500g×1、牛蝎子400g×1、牛肋排400g×1、
羊排块500g×1、羊小腿500g×1、羊蝎子500g×1、带骨羊肉块500g×1
```

注意这个样例**同时给了目标和组合**——所以反向 Agent 的真实用法可能是「以此为起点调优」，而不是从零搜索。本票要先把这件事问清楚。

### 待决策点

1. **反向的真实形态**：(A) 从零搜索——给定约束，从全部可用 SKU 里搜组合；(B) 以给定组合为起点调优——换掉某几个组件以降本/去临期/凑重量；(C) 两者都要。用户样例更像 B，但原话「去综合考量怎么去组这个东西」像 A。**这题不澄清，后面全白做。**
2. **硬约束集合**：目标重量（±容差多少？3800g 必须精确还是 ±200g 可接受）、客户采购价、毛利下限、库存可用份数（票 08 的木桶短板）、牛羊配比（样例是 4:4，是巧合还是要求）、组件数量上限（影响京东订单生产费的首3件/续件档）、装箱可行性（票 02）。
3. **软偏好与权重**：**销售偏好/主推（票 13）**、临期优先（票 08 定的是硬约束还是软偏好）、成本最低、毛利最高、品类均衡、避免用停产/断货品。权重谁定、能否按调用传入、调用方传的权重能否覆盖主推策略的默认权重。
4. **目标函数**：单目标（毛利最大）还是多目标（毛利 + 临期消化 + 库存均衡）？多目标怎么标量化。
5. **输出**：返回 1 个最优解还是 Top N 候选 + 各自的成本拆解与取舍说明？倾向 **Top N + 解释**——人要能看懂为什么推荐这个组合，而不是接受一个黑盒答案。
6. **区域的处理**：反向搜索时区域是输入（发往某地，运费进目标函数）还是输出（这个组合最适合发往哪些区域）？
7. **可行解不存在时**：约束太紧搜不出——返回最接近的解 + 说明是哪条约束卡住了，而不是空手而归。
