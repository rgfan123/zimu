# 08 — 只读探针扩展与生产验证

Type: development-test
Status: resolved
Blocked by: 02 — 基础信息只读补齐, 03 — 库存只读补齐, 04 — 订单杂项只读补齐, 05 — 序列号只读补齐, 06 — 退货退供只读补齐

**What to build:** 将 02–06 新增的全部只读接口接入显式只读探针：一次运行逐个调用每个接口的真实权限状态并输出成功/业务码/requestId/数据存在性；依据结果把京东外部 gate 记录更新为可执行的分类结论（已开通、未授权 2001、缺参数）。探针保持只读，不创建、不取消、不猜测任何单号。

- [x] 探针覆盖全部新增只读接口，每个输出：操作名、成功与否、业务码、requestId 是否存在、数据是否存在。
- [x] 探针不输出密钥、不落盘凭据、不输出 PII。
- [x] 未配置凭据或缺失必填环境变量时，探针明确拒绝并列出缺失键。
- [x] 探针运行结果按「已开通 / 2001 未授权 / 缺参数」分类写入京东外部 gate 记录，标注验证日期与使用的接口清单。
- [x] 探针文件名刻意不以 Test 结尾，普通测试套件不触发外部调用。

## Answer

只读探针已扩展：`JdReadOnlyUatProbe` 现覆盖 37 个只读接口（基础信息 8 + 库存 7 + 订单 9 + 序列号 4 + 退货退供 3 + 仓库域 6，含旧 seam 的 queryProducts/queryStock/queryOutboundOrder/queryTracking），每个输出操作名/成功/业务码/requestId 存在性/数据存在性，不输出密钥与 PII；缺失凭据时一次性列出全部缺失键。京东外部 gate 记录 `gate.md` 已建立（37 行接口清单 + 「已开通/2001 未授权/缺参数」分类口径 + 验证记录位）。探针文件名不以 Test 结尾，普通测试套件不触发。真实环境运行需在配置 `JD_LOP_*` 凭据的环境执行（见 gate.md 的验证方式），运行后按分类更新 gate 记录——这是外部 gate，不属于本地 Mock 验收。
