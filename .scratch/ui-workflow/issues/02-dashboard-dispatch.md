# 02 — 工作台从「报告台」变成「调度台」

**What to build:** 工作台上每一条「待人工介入」都能一键到达能处理它的地方，而不是只告诉运营有 12 条、然后让他自己去菜单里找。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

## 现状

工作台有「待人工介入」KPI 卡与「待人工介入明细」表，但**整个 292 行的页面里只有 1 个跳转**。报警的地方和处理的地方不连通——这是落地页最该做而没做的事。

## 范围与分期

**本票只做薄版本，不等详情路由**：每条待介入链到**带筛选的列表页**（如复核队列按事项类型/责任团队预筛）。这个现在就能做，且 #62（详情改真实路由）落地后只需把目标 URL 换成详情地址，改动很小。

不要为了等 #62 而搁置——每天都在损耗的东西先止血。

## 验收标准

- [ ] 「待人工介入」明细的每一行可点击直达能处理它的位置，且目标已按该行上下文预筛
- [ ] KPI 卡数字可点击，进入对应的完整列表
- [ ] 跳转目标的筛选条件反映在 URL 上，可分享
- [ ] 无待办时空态明确（「当前无待人工介入」），不是空表格
- [ ] 跳转不丢失工作台的时间范围口径（今日/7 日）
