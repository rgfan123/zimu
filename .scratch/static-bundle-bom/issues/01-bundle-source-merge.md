# 01 — 新旧礼包源文件合并规则

Type: research
Status: closed
Blocked by: None — can start immediately

Label: wayfinder:research

## Question

静态礼包主数据的权威来源是「大者国风上架品（内容详情）-202605更新(1).xlsx」（36 个礼包）与「京东商品编号.xlsx」Sheet2（23 个礼包）**两份文件合并**。合并规则是什么？

需要明确：
- 两份文件的礼包集合重叠情况：新文件 36 个礼包（带商品条码、税率、成本），旧 Sheet2 23 个礼包（纯名称+EMG+数量，无条码）；名称大量近似但几乎都不完全相同（新文件带「（BJ）」后缀、名称差异如「牛羊礼包5800g」vs「牛羊礼包5800g (BJ)」）；
- 同一礼包在两份文件中的组件是否一致（数量、EMG 编码）——不一致时以哪份为准；
- 旧 Sheet2 独有、新文件没有的礼包（如「牛羊肉豪华大礼包7520g」「中秋礼包1」）是否也纳入主数据；
- 合并后的礼包标识（以新文件条码为主键？旧文件礼包无条码怎么办——是否生成内部标识）；
- 组件缺失京东商品编号（新文件 165 个组件行仅 70 个带 EMG）怎么表示：导入但标记待补，还是导入前必须补齐；
- 输出：一份**合并后的权威礼包清单草案**（礼包标识、名称、组件名称+数量+EMG、条码、税率、成本），作为后续 schema/导入票的输入。

## Assets

（research 子代理产出：`.scratch/static-bundle-bom/research/01-bundle-source-merge.md` + 合并清单）

## Resolution

新旧两份合并为 **49 个礼包**（11 重叠 + 25 仅新 + 11 仅旧 + 2 旧右块命名礼包），336 个组件行，其中 319 个带 EMG（新文件自带 187 + 旧文件回填 59 + 字典回填 74），仅 16 个缺 EMG（4.8%，集中在猪肉类与新品火锅单品）。

可执行合并规则（详见 research/01-bundle-source-merge.md §5）：
- **主键 = 商品条码**（新文件 9250/9260 开头 13 位）；名称归一键（去空白/（BJ）后缀/品牌前缀/【京东配送】+ 全半角统一）完全一致判定重叠；组件相似度 ≥85% 且重量差 ≤200g 为同系兜底；
- **冲突以新文件为准**（2026-05 更新版）：新组件缺 EMG 时按名称归一键回填旧文件 EMG（标记来源），新旧都带且不一致时以新文件为准并记日志；
- 仅旧礼包生成内部标识 `BUNDLE-01…11` / `BUNDLE-R01/R02`（无条码、无税率/成本，标注 `need_business_confirmation=true`）；旧 Sheet2 右块 3 段无名/疑似错位数据不纳入；
- 缺 EMG 一律「导入 + 标记待补」，不阻断导入；待补清单导出给采购/运营补录。

附录 A 为 49 礼包权威清单（含条码、税率 9%、大者结算成本），附录 B 为全组件明细 CSV（`01-merged-components.csv`），复现脚本 `01-parse-bundles.py`。
