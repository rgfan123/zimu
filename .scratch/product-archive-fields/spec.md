# 商品档案新字段 — Spec

## 背景

商品档案（前端 `/product/skus`，后端 `/api/v1/skus` 与 `/api/v1/products`）需要新增运营字段。已与需求方确认口径：

## 字段口径（全部落在「商品 Product」层）

| 字段 | 语义 | 存储/校验 |
|---|---|---|
| 毛利 | 毛利额 = 零售价 − 进货价 − 其他成本；**读时实时计算，不落库**；任一输入未填则显示未定价 | `margin` 为投影派生字段（decimal string，两位小数） |
| 零售价 / 进货价 / 其他成本 | 毛利计算输入，商品层新增 | `NUMERIC(14,2)`，非负，null = 未定价；沿用现有 decimal-string 契约 |
| 商品标签 | 自由多选文本，可输入可复用；已用过的标签自动进候选 | JSONB 字符串数组，≤10 个，每个 ≤32 字符，去重 |
| 主图 | 单张，可上传/替换/清除 | 内容寻址存储；`main_image_ref` 存文件引用 |
| 原料 | 自由文本 | `VARCHAR`，可空 |
| 上市周期 | 上架日期 ~ 下架日期，可只填开始 | `DATE` 起止，`from <= until` |
| 发货时效 | 小时数 | 正整数；展示为「X小时内发货」 |

## 边界

- 不做默认值回填：已有商品新字段均为空（毛利显示未定价）。
- 毛利只显示金额，不显示毛利率。
- 商品层价格与 SKU 层价格（`skus.purchase_price/retail_price`）相互独立，互不影响。
