# 03: 外壳运行期模块可见性

**What to build:** 应用外壳在启动时读取一份由后端下发的「当前已开放模块」清单，并据此过滤侧边栏导航树。这样同一个前端镜像可以同时服务已接通与未接通的环境，菜单不再承诺系统给不出的能力。

导航树仍是唯一事实源：运行期清单只做**过滤**，不新增节点、不改写路径。因此既有 URL 直达、侧边栏归属解析与隐藏页的面包屑行为全部不受影响。

**Blocked by:** None (can start immediately)
