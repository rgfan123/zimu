# 09: 原料库存页接入真实数据

**What to build:** 原料库存页面呈现来自上游的真实原料清单、批次与结存数量，并标明取数时刻，使运营在履约中台内就能看到原料事实，不必再去问 Agent 或找人查。

本票**不做**原料消耗、订单占用或「这单原料够不够」——履约中台的商品身份与原料之间目前不存在任何连接键（商品档案上只有自由文本的商品原料描述，静态礼包明确不单独计库存），在映射建立之前这类功能没有可计算的基础。

**Blocked by:** 06（导航准入与空态）、08（只读网关）

**Status:** ready-for-agent

- [ ] 页面列出原料清单与批次，并显示结存数量与单位
- [ ] 页面显示数据的取数时刻，运营能判断口径新旧
- [ ] 上游各类失败按票 08 的错误码分别呈现，与票 06 建立的空态措辞一致
- [ ] 页面为只读，不提供任何出入库操作入口
- [ ] 页面不呈现任何「原料够不够发货」类推断
