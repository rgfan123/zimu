# 08: 原料库存只读网关

**What to build:** 履约中台后端新增一条通向原料库存的**只读**通路，形态与既有的客户中心远端只读网关一致，不为第二个外部系统发明第二套做法。遵守既有边界：外部系统一律通过接口接入，不直接写业务表。

复用的是网关的**性质**，不是照搬那个大而全的工具类——后者的体积主要来自「客户身份不能猜」带来的运行级作用域与个人信息白名单，原料库存没有这个约束。

**Blocked by:** 07（上游 HTTP MCP 面）

**Status:** ready-for-agent

- [ ] 端点的主机与端口以白名单方式钉死，配置中的任意 URL 不被接受（防 SSRF）
- [ ] 上游返回结构变化时给出稳定的契约漂移错误码，而不是静默解析成空结果
- [ ] 不可用 / 未配置 / 鉴权失败 / 契约漂移各有独立且稳定的错误码，供前端分别呈现
- [ ] 每次远端读取落读取存证（取数时刻与响应摘要），失败落独立的失败记录
- [ ] 通路为纯只读，不提供任何写入原料库存的能力
- [ ] 未配置时整条通路不注册，且不影响系统其余部分启动
