# 11: 客户中心写路径开启

**What to build:** 运营能在客户跟进页把订单草稿关联到已有客户，或对未匹配的客户发起「创建新客户」——客户编码由系统生成，不由人手工维护也不由模型生成。所有写操作必须经过授权人工确认，远端档案不会被自动流程悄悄改掉。

**Blocked by:** 10（对端部署与读路径通电）

**Status:** ready-for-agent

- [ ] 读路径已验证稳定运行后才开启写开关
- [ ] 关联既有客户与创建新客户两条路径都可用，且与票 02 补齐的契约取值一致
- [ ] 每次写入前有明确的人工确认步骤，未确认不写
- [ ] 写入具备幂等性，重复提交不产生重复档案
- [ ] 写入失败时有独立的失败记录，不静默降级
- [ ] 新客户编码由系统生成
