# 02: 补齐客户中心任务类型的契约漂移

**What to build:** 客户跟进的执行任务类型有两种取值——关联既有客户、创建新客户。数据库约束与后端执行器都已支持两种，但对外契约与前端类型只声明了其中一种。补齐后三处一致，前端不再需要绕过类型系统才能表达「创建新客户」这条路径。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 对外契约中该任务类型的取值集合包含两种取值
- [ ] 前端类型定义与契约一致
- [ ] 存在一个断言两种取值都被接受的测试
- [ ] 契约与数据库约束、后端执行器三处取值集合一致，有测试或校验证明
