# 05: MCP 开放面只读视图

**What to build:** 系统管理员在界面上就能看出「此刻对外开放了哪些 MCP 模块、每个模块下有哪些工具」，不必进容器翻环境变量。这是配置反转（票 01）之后的核对手段：改完配置能立刻确认结果符合预期。

**Blocked by:** 01（MCP 模块语义反转）

**Status:** ready-for-agent

- [ ] 页面按模块分组列出当前已注册的 MCP 工具名与用途摘要
- [ ] 页面明确区分「已知但未开放」与「已开放」两类模块
- [ ] 视图为纯只读，不提供任何在界面上改开放面的能力
- [ ] 该页面归入系统与接入板块，按菜单准入规则处置可见性，不突破可见子项上限
- [ ] 未开放任何模块时页面如实呈现空态，不报错
