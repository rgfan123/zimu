# 01: MCP 模块开放语义反转为 fail-safe

**What to build:** 系统管理员不再需要「记得配置」才安全。未配置 MCP 模块开放清单时，系统不注册任何 MCP 工具（空集），而不是像现在这样注册全部已知模块。想用 MCP 的环境必须显式列出模块名；列出未知模块名时部署直接失败（既有行为，保留）。环境变量样例文件补齐这一项，使照样例拉起的环境有正确且安全的默认。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 未配置模块清单时，MCP 工具列表为空，工具调用一律拒绝（列表与调用行为一致，不存在「列表藏起来但还能调用」）
- [ ] 显式配置模块名时，只注册列出模块的工具
- [ ] 配置未知模块名时启动失败，错误信息包含未知名与已知模块全集
- [ ] 环境变量样例文件包含该配置项，其默认值与生产当前显式配置一致，并注明「留空 = 不开放任何 MCP 工具」
- [ ] 既有生产配置（显式三模块）行为不变，回归测试证明这一点
