**Type:** task

## Question

把 `A产品成本核算26.3.29.xlsx` 一次性导入 `fulfillment_hub`，作为成本档案的种子数据。

**这是一次性种子，不是长期管道**（决策 3）：导完之后 DB 是唯一真源，Excel 不再参与，成本维护走商品档案 API/页面。

### 源数据（已勘察）

| Sheet | 行数 | 内容 |
|---|---|---|
| `成品` | 113 | 自有成品，~47 列完整成本构成；品牌：子牧 75 / 小龙坎 10 / 蒙元鸵 9 / 东乡贡羊 9 / 窦清源 4；肉类：牛肉 47 / 羊肉 41 / 其他 |
| `包材` | 5 | 自有包材，**缺重量与体积列**（见票 02） |
| `送仓经销品` | ~109 | 采购价/供货价/零售价 + 毛利率，表头在第 3~5 行（两层表头） |
| `一件代发经销品` | ~72 | 采购成本/供货价/零售价 + 产地/发货仓/快递公司/服务区域/发货时效/京东链接，表头在第 2~4 行 |

### 已知的导入陷阱

1. **两层表头**：`送仓经销品` 第 3 行是主表头、第 5 行是单位行（`元/箱` / `元/支`）；`一件代发经销品` 第 2 行主表头、第 4 行单位行。**同一列有「元/箱」和「元/支」两个口径，混淆会让成本差一个数量级**。
2. **`成品` 表 37 列无表头但有数据**（值 = 毛利率，可由 售价与成本 反算验证）；列 48+ 稀疏散落数字，含义不明，导入前需确认是否为业务数据。
3. **`经营状态` 分布**：停产 42 / 空 45 / 研发 18 / 新品 4 / 断货 1。**空值占 40%**——是在售还是未维护？导入时如何映射到 `products.active`，需确认。
4. **`AJ 是成本` 是笔误**：AJ = 售价，AI = 线下供货成本/份。导入映射以 map 决策 2 为准，不按用户原话。
5. **浮点精度**：源表大量 15 位小数（如 `55.5555555555556`），落库前按票 01 定的精度舍入，**舍入规则要记录**。
6. **产品编码**：`成品` 表有 `国条`（国标条码），经销品表有 `产品编码` + `产品条码`，三者格式不同。`skus.sku_code` 必须是 `SKU-{provider_code}-{6位流水}` 格式，源编码归 `barcode` 或 `sku_aliases`。
7. **重复与冲突**：`原切牛肋条` 出现两行（500g / 750g），是不同 SKU 不是重复；但需检查是否存在真重复。

### 要做的

1. 按票 01/02 定的 schema 写导入脚本（幂等、可重跑、空库才播或按 upsert 键覆盖）。
2. 产出**导入报告**：每 sheet 的成功/跳过/失败行数，失败原因清单，以及**未映射列清单**（哪些源列没有落库位置）。
3. 校验：随机抽样人工核对；用样例礼包的 8 个组件做端到端验证——导入后按票 07 的公式算出的成本应与人工核算一致。
4. 源文件归档到仓库内（`docs/` 或 `.scratch/`），标注版本 `26.3.29`，便于日后追溯导入自哪一版。
