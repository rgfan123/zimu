# 01 — 扩展克制的 SaaS 主题 Token

**Type:** implementation

**What to build:** 用户在一个代表性的 SKU 映射管理页面看到中性、清晰、低饱和的 SaaS 视觉基线；主题同时为后续页面提供单一品牌色、语义色、文字、背景、边框和图表色阶，而未迁移页面仍可正常工作。

**Blocked by:** None — can start immediately

**Status:** resolved

**Claimed by:** codex-main → `/root/saas_theme_01`

- [x] 默认界面以中性背景、白色或近白表面、清晰文字层级和低对比边框为主，只使用一个低饱和品牌色表达主要操作与非语义强调。
- [x] 成功、警告、错误和信息色只表达对应语义，不被普通分类或装饰元素借用。
- [x] 主题 Token 成为组件与图表配色的共同来源；旧颜色在迁移期间可兼容，但新页面不得新增独立调色板。
- [x] SKU 映射管理页面的表格、表单、主要操作、提示、错误和空态完整采用新主题，业务行为保持不变。
- [x] 同一区域只保留一个主要视觉焦点，次要按钮、标签和图标不与主要操作争夺注意力。
- [x] 代表页面在常用桌面宽度下完成截图对比，并验证正文、控件、状态文本和焦点态的可读对比度。
- [x] 用户反馈后的主题不再呈现沉闷灰膜：画布/表面更清透，品牌蓝具有清晰操作焦点，并提供共享蓝/青/紫数据系列 Token。
- [x] 重新以 100% 浏览器缩放、整数视口和 DPR=2 原图验收；同时提供 1:1 视口或局部图，不用长截图缩略预览代表渲染清晰度。
