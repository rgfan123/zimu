# MVP Public-ready 产品画像

- **定位**：面向内部运营、履约、采购与管理人员的企业级订单履约 ERP，不是面向消费者的商城。
- **受众**：一线运营查看待办和异常，履约/采购人员处理作业，管理者查看指标与追责证据。
- **功能**：多渠道订单归一、客户/SKU 映射、人工复核、履约与采购协同、Excel 导入导出、京东仓配、审计与经营分析。
- **核心理念**：数据诚实、范围隔离、不猜测映射、不把 Mock 冒充真实、所有人工与外部操作可审计。
- **关键动线**：订单/文件进入 → 客户与 SKU 映射 → 人工复核或自动履约 → 发货/采购 → 运单回传 → 来源回填 → 审计/分析。
- **语气基调**：正式、简洁、可执行；少量状态标签，不用卖萌、emoji、开发黑话或模糊甩锅文案。
- **边界红线**：不暴露密钥、Token、PII、堆栈、内部 URL 或原始 SDK 报错；Demo/Mock 必须显式标识且与 BUSINESS 隔离；未实测权限不得标为已就绪。
