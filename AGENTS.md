# Repository agent guidance

## Agent skills

### Issue tracker

Issues are tracked as **GitHub Issues** in `rgfan123/zimu` (new issues are filed there via `gh`). `.scratch/` now serves as historical archive for past tickets; migrated tickets carry a `**GitHub:** <url>` link. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default Matt Pocock triage role names. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain layout rooted at `CONTEXT.md`. See `docs/agents/domain.md`.
